# Content pages

Narrivelle provides templates for pages, contact, FAQ, About, Blog, Article, collections, search, 404, password, and Gift Card routes. Choose a template from the relevant resource in Shopify admin, then customize its supported sections in the theme editor.

## Pages

- Use the default **Page** template for normal reading pages.
- Use **page.contact** for a Shopify-native contact form.
- Use **page.faq** for an FAQ page with editable FAQ blocks.
- Use **page.about** for the dedicated About composition: hero, story, values, and closing sections.

The native contact form is suitable for store contact messages. It is not the future public Theme Store support form, which needs file upload and an auto-response workflow.

## Blog and article

Create blogs and articles in Shopify admin. The theme presents the blog listing, article content, image and metadata when available. Use meaningful article titles and excerpts, and check articles with a missing image or author before publishing.

## Collections and search

Create collections and configure search/filter data in Shopify admin. Collection and search results use Shopify URLs, pagination, sorting, and filter data. Do not add filters that promise values Shopify has not configured.

See [Collections, product cards, and search](catalog-and-search.md) for the complete setup guide.

## 404 and password

The 404 template provides recovery guidance for invalid URLs. The password template uses your store's password configuration and message. Test both before launch, including any long store message.

## Gift Cards

Gift Card pages are generated from Shopify-issued Gift Cards. Status, balance, expiry, Apple Wallet availability, and the redeemable code are Shopify data. An active eligible card can show its QR code; disabled or expired cards must not be presented as redeemable.
