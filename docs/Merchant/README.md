# Narrivelle merchant documentation

Version: **1.0.0**  
Status: **public documentation source**
Documentation: <https://amazinsolution.com/themes/narrivelle/docs/>

Narrivelle is an editorial commerce theme for fashion, apparel, and lifestyle stores. This guide explains the settings and sections included in the theme. It does not replace Shopify's own documentation for checkout, payments, customer accounts, delivery, taxes, or app-provided functionality.

## Before you begin

1. In Shopify admin, go to **Online Store → Themes**.
2. Duplicate your live theme before making substantial changes.
3. Open **Customize** on the copy, make one related change at a time, then preview it on desktop and mobile.
4. Save only after checking the relevant storefront page.

Do not edit theme code unless you are comfortable maintaining the change. Custom code can be overwritten by a future update or conflict with apps.

## What Shopify continues to manage

Shopify and installed providers determine checkout, payment methods, accelerated checkout eligibility, Shop Pay Installments, customer accounts, pickup locations, tax calculations, gift-card status, Apple Wallet availability, and app data. Narrivelle displays the native Shopify surfaces where available; it does not create or override those decisions.

## Getting help

Submit support requests through <https://amazinsolution.com/themes/narrivelle/support/>. Include your store URL, theme version, a description of the problem, steps to reproduce it, and screenshots or a short recording. See the [support policy](support-policy.md) for the information that a support request needs.
