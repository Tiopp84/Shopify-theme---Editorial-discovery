# Narrivelle support policy

Status: **draft — publish with the public support form before launch**

## Response commitment

AmazinPro aims to respond to complete Narrivelle support requests within **two business days**. Critical defects that prevent normal storefront use receive priority handling.

## Included support

- Reproducible bugs in an unmodified supported version of Narrivelle
- Broken layouts, links, or theme behavior
- Questions about documented theme settings and included sections/blocks
- Guidance for reproducing a problem on a duplicate theme

## Not included in standard support

- Custom code, bespoke design work, or custom feature development
- Third-party app behavior, app data, or provider outages
- Shopify checkout, payment, customer-account, tax, fulfillment, or pickup decisions
- Store setup, product-data entry, marketing, or content production
- Problems introduced by direct code edits or unsupported tutorials

## Before submitting a request

Provide:

1. Your name and email address.
2. Your Shopify store URL, for example `yourstore.myshopify.com`.
3. Theme name and version.
4. A concise description of the problem and its business impact.
5. Steps to reproduce, the affected URL, expected behavior, and actual behavior.
6. Screenshots, screen recordings, and browser/device details when useful.

## Public support form requirements

The published form must collect name, email, store URL, theme name, version, and a problem description. It must allow image/file upload and send an automatic receipt email. Do not ask for a merchant's budget, phone number, or project type in this support form.

## Privacy

Use request details and attachments only to investigate and respond to the support request. Publish the final privacy/contact details alongside the public form before launch.
