# Merchant pre-publish checklist

Run this checklist on an unpublished duplicate before publishing a major content or settings update.

## Store content

- [ ] Logo, favicon, menus, social links, policies, country/language settings, and newsletter copy are complete.
- [ ] Products have accurate titles, prices, variants, availability, descriptions, media, and alt text.
- [ ] Collections, search filters, recommendations, and product links use real Shopify data.
- [ ] No placeholder copy, unselected product/collection, broken link, or test image remains.

## Theme Editor

- [ ] Home page sections have a deliberate order and no accidental empty space.
- [ ] Header and Footer are checked globally after every navigation or branding change.
- [ ] Product blocks include a usable Product form and an appropriate purchase hierarchy.
- [ ] Custom Liquid and app blocks are tested on their target templates.
- [ ] Contact, FAQ, About, Blog, Article, 404, Password, Search, Cart, and Gift Card routes have been reviewed where relevant to the store.

## Customer journey

- [ ] A customer can navigate Home → Collection/Search → Product → Cart → Shopify checkout.
- [ ] Variant selection, add to cart, cart quantity/remove, and standard checkout work.
- [ ] Payment, pickup, Shop Pay, customer account, gift-card, and Follow on Shop surfaces are checked only where the store/provider actually makes them available.
- [ ] Cart tax/discount/shipping messages do not conflict with Shopify data.

## Responsive and accessibility review

- [ ] Check Compact (under 48rem), Tablet (48–63.99rem), and Desktop (64rem and above).
- [ ] Check long text, missing images, keyboard navigation, visible focus, and 200% zoom.
- [ ] Check reduced motion and dialogs/drawers can be closed with their normal controls and Escape where applicable.

## Publish decision

- [ ] The duplicate has been previewed using the actual store catalog and apps.
- [ ] A rollback copy of the current published theme exists.
- [ ] The person publishing understands what changed and which store pages were checked.

For a Theme Store submission, this merchant checklist is not sufficient. Provider, browser, clean-install, commercial listing, support-form, and Shopify review requirements remain separate release gates.
