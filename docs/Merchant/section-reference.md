# Section reference

Use **Add section** only on templates where a section appears in the Theme Editor picker. Narrivelle deliberately limits placement so a commerce or editorial section is not offered in an unrelated context. Section availability can vary by template.

## Home and editorial sections

| Section | Purpose and main controls |
|---|---|
| Editorial hero | Main campaign image/mobile image, text protection, eyebrow, heading, text, CTA, text position/alignment, desktop/mobile height, and text color. |
| Featured edit | A selected collection with heading, title treatment, price/index visibility, desktop grid, image ratio, and second-image option. |
| Material & craft | Two images, editorial copy/CTA, text size/alignment/position, image size, media side, and background. |
| Shoppable hero | A campaign image plus product hotspot blocks. Controls include separate mobile editing mode, image/text protection, copy, layout, height, hotspot styling, and colors. Each hotspot selects a real product and its position. |
| Shoppable story | Intro copy and independent Story product blocks. Each block selects a product, optional editorial image, and caption. It never creates a bundle or shared product price. |
| Pinned visual story | Intro settings plus Chapter blocks. Each chapter has an image, copy, and optional CTA. Configure chapter index/type/alignment, media geometry, motion options, and background. |
| Outfit composition | A look image, editorial introduction, and independent Outfit item blocks. Each item selects a product and optional title override; the section does not create a bundle. |
| Editorial details | Heading/intro plus Detail blocks. A detail can use an image or icon, heading, text, and optional CTA. |
| Scrolling text | Repeating Message blocks with text and optional links, plus visual/motion settings. Keep messages short and avoid critical information that only appears while moving. |
| Email signup | Heading and supporting copy above Shopify's newsletter form. |
| Featured product | A selected product with native Product blocks, app blocks, media layout, product information, and purchase controls. Select the product before arranging its blocks. |
| Collection list | Heading/intro/layout plus Collection card blocks. Cards select a collection, optional title override, and focal point. |
| Contact form | A Shopify-native contact form with editorial/centred layout, framed/minimal surface, heading, and intro. |
| Custom Liquid | A small merchant-authored Liquid insertion point. See [Custom Liquid and app blocks](custom-liquid-apps.md). |

## Product sections and blocks

| Item | Purpose and main controls |
|---|---|
| Product | Main product page. Controls gallery layout, thumbnail position/visibility, desktop media side, and media width. |
| Product vendor/title/price/SKU/availability/description | Shopify-derived product information blocks. Reorder them to suit the product-information hierarchy. |
| Product form | Variant selection, quantity and add-to-cart. It can show the native dynamic checkout button and link to a selected size-guide Page. |
| Product payment terms | Shopify-native installment/payment-terms surface when eligible. |
| Product pickup availability | Shopify-native pickup surface that updates with the selected variant when store data is available. |
| Product collapsible | Merchant heading and rich-text detail. Use for fit, materials, care, or delivery information. |
| Product reassurance | Heading, rich text, optional Shopify Page link, and link label. |
| Product Custom Liquid | Custom Liquid inside the Product information block list. |
| Product app block | An installed app's own block. The app provider owns its behavior and support. |
| Product recommendations | Product-template section with heading, related/complementary intent, product limit, tablet/desktop columns, and image ratio. Shopify supplies recommendations. |

## Catalog and discovery sections

| Section | Purpose and main controls |
|---|---|
| Collection header | Collection image/title visibility, image height, title position/alignment, overlay, and text color. |
| Collection product grid | Grid columns, products per page, image ratio, variant/quick-view options, description, filter layout, count, filtering, and sorting. |
| All products header | Eyebrow, heading, intro, and alignment for the all-products collection. |
| Collections grid | Heading, intro, excluded collections, alignment, items per row, and spacing on the List collections template. |
| Search | Product-grid columns/image ratio plus filtering, sorting, and desktop filter layout. |
| Search page suggestions | Shopify predictive product suggestions on the Search template. |
| Predictive search | Global search enhancement used by the header; configure behavior in Theme settings rather than as a page section. |

## Content and utility sections

| Section | Purpose and main controls |
|---|---|
| Page | Default Page template. Optional image, text protection, eyebrow/banner text, heading size, banner style, height, and style-specific positions. |
| About hero | One to five Slide blocks with desktop/mobile images, copy, position, and text protection; section settings cover height, text color, and optional autoplay. |
| About story | Image, copy, and left/right media position. |
| About values | Intro content and Value blocks with heading/text. |
| About closing | Editorial CTA with eyebrow, heading, text, link label, and link. |
| FAQ | FAQ item blocks plus layout, optional heading/intro, divided/framed item style, and numbering. |
| Blog | Editorial/compact card density, media visibility/ratio, author, date, and read-time visibility. |
| Article | Article media treatment, author/date/read-time visibility, and optional sidebar author profile. |
| Related stories | A heading for other articles from the same blog. |
| 404 | Fixed recovery page for unavailable routes. |
| Password | Fixed password-page treatment driven by Shopify password settings. |
| Cart / Cart drawer | Native cart surfaces. Cart data, discount, checkout, and payment decisions remain Shopify-owned. |
| Pickup availability renderer | Internal Shopify Section Rendering response used by the Product pickup block; it is not an addable page section. |

## Editing rules

- Start with real content/resources, then adjust layout.
- Hide a section only when its absence is intentional; do not leave placeholder copy in a live page.
- Check long copy, missing media, and one mobile width before publishing.
- Do not use a section to imitate checkout, payment, customer-account, pickup, or app-native functionality.
