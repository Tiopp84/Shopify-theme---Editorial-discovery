# Release notes

## Version 1.0.0 — Initial release candidate

### Highlights

- Editorial home-page compositions and product-led storytelling sections.
- Product, collection, search, cart, content-page, and Gift Card templates.
- Native Shopify surfaces for accelerated checkout, pickup availability, payment terms, Follow on Shop, and provider-owned Gift Card/Apple Wallet states where eligible.
- Merchant-editable global settings, Product blocks, Featured product app blocks, and Custom Liquid insertion points.

### Important notes

- Provider-owned features only appear when Shopify and the relevant provider make them eligible.
- Merchants should review a duplicate theme and test their own catalog, apps, markets, and payment configuration before publishing.
- Public documentation, public support contact details, and final Theme Store release evidence are still pending.
