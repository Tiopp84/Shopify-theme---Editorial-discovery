# 10 — Final release gate

Không submit nếu còn mục bắt buộc chưa đạt. Mỗi nhóm ghi owner/date/evidence.

## A. Eligibility/originality

- [ ] Skeleton/original repository; không port Dawn/Horizon/commercial code.
- [ ] Khác biệt ở navigation, cards, media, product và composition.
- [ ] Names hợp lệ; licenses/third-party notices đầy đủ.

## B. Architecture/features

- [ ] Required templates và JSON sections render.
- [ ] Header/footer groups; Custom Liquid/app block points.
- [ ] Product elements block hóa.
- [ ] Discounts, unit price, selling plans, quantity rules, accelerated checkout.
- [ ] Gift card, search, localization và customer flows pass.

## C. Code quality

- [ ] Theme Check zero unapproved offenses.
- [ ] Không orphan/dead/duplicate assets, debug/demo code, remote runtime.
- [ ] Schema/JSON/locale/LiquidDoc hợp lệ; không secrets/store IDs.

## D. Design/merchant UX

- [ ] Art direction nhất quán; presets/defaults polished.
- [ ] Settings rõ và đúng terminology.
- [ ] Empty resources và Theme Editor lifecycle pass.
- [ ] Long content/translations không vỡ.

## E. Accessibility/performance

- [ ] Accessibility average ≥90, internal target ≥95.
- [ ] Keyboard/screen-reader/focus/contrast/zoom/reduced-motion pass.
- [ ] Performance average ≥60, internal target ≥75.
- [ ] Home/product/collection desktop/mobile đo bằng content thật.
- [ ] CLS/image sizing/asset loading đạt budget.

## F. Functional/compatibility

- [ ] Product data, discovery/search/filter, variant/media/form pass.
- [ ] Cart/checkout path và empty/loading/error states pass.
- [ ] Browser/mobile/webview matrix pass.

## G. Clean install/demo

- [ ] ZIP cài trên fresh dev store; không demo URI/handles/IDs.
- [ ] Không broken image/link/setting.
- [ ] Mỗi preset đạt demo parity; assets có license.

## H. Docs/support/commercial

- [ ] Docs/FAQ/troubleshooting và support form public.
- [ ] Autoresponder, SLA ≤2 business days và escalation sẵn sàng.
- [ ] Version/release notes/listing/screenshots/demo URLs đúng.
- [ ] ZIP từ đúng commit, lưu hash; không P0/P1.
- [ ] Official requirements được re-check trong tuần submit.
