# 07 — Demo, presets, documentation và support

## Presets và demo

Bản đầu: hai presets cùng capabilities nhưng art direction khác nhau, ví dụ editorial fashion và streetwear/accessories.

- [ ] Home/collection/product/cart/search/content pages hoàn chỉnh.
- [ ] Catalog thể hiện đủ variant/media/price states.
- [ ] Navigation/mega menu và mobile composition dùng thật.
- [ ] Không fake reviews, stock, viewers hoặc urgency.
- [ ] Không dùng app khiến native feature bị hiểu sai.
- [ ] Copy/images có quyền thương mại; không broken link.
- [ ] Install state và demo parity về layout/palette/typography.

## Clean install

Package không chứa demo `shopify://shop_images`, custom handles/metafields, brand/social/tracking IDs hoặc credentials. Resource rỗng phải tự ẩn/onboard hợp lý. Test ZIP trên development store mới.

## Documentation

- Getting started, settings/design system.
- Header/mega menu/localization.
- Cards/swatches/badges/quick add.
- Gallery/variants/size guide/product blocks.
- Filters/cart và từng section khác biệt.
- Metafields/metaobjects/app blocks.
- Accessibility/performance guidance.
- FAQ, troubleshooting, changelog, browser/support policy.

Mỗi bài có prerequisites, steps, expected result và screenshots cập nhật.

## Support

Form có name, email, store URL, theme/version, problem textarea, file upload và autoresponder. SLA phản hồi ≤2 business days; critical bug xử lý ngay. Có severity P0–P3, escalation path, ticket tags và backup responder. Tách support theme khỏi custom development.

## Listing assets và exit

- [ ] Names, descriptions, feature list, screenshots, demo URLs.
- [ ] Documentation/support URLs và release notes.
- [ ] Hai presets đạt parity; clean install pass.
- [ ] Docs/FAQ/form public; listing không overclaim.
- [ ] Asset licenses đầy đủ.
