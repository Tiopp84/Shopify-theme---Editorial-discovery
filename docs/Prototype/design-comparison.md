# Narrivelle prototype differentiation review

Date: 2026-07-19  
Status: **INTERNAL COMPARISON COMPLETE — OWNER REVIEW PENDING**

This comparison uses the Phase 0 evidence in `../Discovery/competitive-analysis.md`, `../Discovery/tier-1-live-demo-audit.md`, and `../Discovery/tier-1-interaction-checklist.md`. It compares systems and customer outcomes, not superficial colour or font choices.

| Dimension | Common baseline / observed reference pattern | Narrivelle prototype rule | Differentiation test |
|---|---|---|---|
| Home composition | Conventional campaign hero followed by product modules | A journal issue structure: edition marker, thesis-led hero, numbered story index, then product destinations | Removing palette and type should still leave a recognisable editorial sequence and numbered narrative grammar |
| Collection discovery | Uniform product grid with filters outside the merchandising narrative | Collection thesis precedes a stable commerce toolbar; cards preserve the story numbering without changing product-count semantics | Editorial identity remains visible while filters/history and product count behave conventionally |
| Product-card action | Hover quick add or universal quick view | Action language distinguishes direct safe add from “Choose options”; keyboard/touch receive the same path | A multi-variant item can never silently add a default variant |
| Product decision | Gallery and product form with confidence content lower in the page | Variant source-of-truth is adjacent to fit, material, and delivery disclosures; sticky mobile action yields to the global task bar | Colour/size change media, price, SKU, label, and add context together |
| Cart presentation | Drawer/page may lead with threshold, cross-sell, or promotional content | Bag begins with selected variant, quantity, line price, subtotal, and checkout; no incentive or implied bundle | Removing all optional editorial material does not weaken checkout comprehension |
| Mobile shell | Top drawer, bottom task bar, or theme-specific quick-view sheet | Header retains brand context; five-task bar provides reach; PDP purchase bar sits above rather than behind it | At mobile widths both global tasks and purchase action remain visible without covering each other |
| State language | Decorative disabled state or generic errors | Availability is textual, invalid choices cannot be selected, delayed update and recovery copy are explicit | Meaning survives without colour and previous cart quantity survives simulated failure |

## Explicit non-claims

- A bottom task bar, bottom sheet, quick add, editorial hero, or product-confidence block alone is not unique; these are market-parity patterns.
- CSS placeholder art is not final art direction and cannot be used as evidence of differentiation.
- This prototype does not claim Dawn, Horizon, or any commercial theme as a source or layout template.

## Review decision

The prototype has a defensible system-level direction: journal issue structure + numbered story grammar + variant-safe action language + commerce-first cart. It is sufficiently distinct to continue Phase 1 iteration, but M1 must remain open until the owner approves desktop/mobile composition and the accessibility review is performed at true 320 px and 375 px CSS viewports.
